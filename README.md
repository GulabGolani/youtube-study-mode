# YouTube Study Mode — UX/UI Case Study

A premium mobile UX/UI concept for a new YouTube feature focused on learning and focus. Designed with Material Design 3, dark mode, and AI-first interactions.

**Live Demo:** [View on GitHub Pages](https://yourusername.github.io/youtube-study-mode)

## ✨ Overview

YouTube hosts the world's largest library of free education — but the interface is built for entertainment, not learning. **Study Mode** reimagines YouTube as a focused learning environment with:

- 🎯 **Distraction-free** playback (no recommendations)
- 🤖 **AI summaries** generated in <1 second
- 📝 **Smart notes** with timestamp linking
- 📊 **Learning dashboard** with streaks & progress
- 🔍 **Search inside videos** (not just titles)

## 📱 Screens Included

1. **Home Feed** — Personalized educational recommendations, continue learning, AI playlists
2. **Smart Watch** — Video player with AI summary, chapter timeline, focus mode
3. **AI Notes & Highlights** — Timestamp-linked notes, auto key takeaways
4. **Smart Comments** — AI-summarized, topic-grouped, toxicity-filtered
5. **Learning Dashboard** — Streaks, hours learned, skill progress, achievements
6. **Smart Search** — Search inside video content, voice search, AI answers
7. **Tablet/Desktop** — Multi-panel workspace for deep learning

## 🎨 Design System

- **Framework:** React 19 + Vite + Tailwind CSS 4
- **Design Language:** Google Material Design 3
- **Colors:** Deep dark (#08080A), YouTube Red (#FF0033), AI Gradient
- **Typography:** Google Sans, Roboto, JetBrains Mono
- **Icons:** Lucide React
